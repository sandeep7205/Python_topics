##### Each movie entry contains:



* **id**: Unique identifier for the movie
* **title**: Movie title
* **genres**: A stringified list of genres (e.g., "Action", "Comedy")
* **release**\_**date**: Official release date
* **vote**\_**average**: Average user rating (0–10)
* **vote**\_**count**: Number of user votes
* **revenue**: Box office revenue (USD)
* **runtime**: Duration of the movie in minutes
* **overview**: Brief plot summary
* **original**\_**language**: Original spoken language of the movie
* **popularity**: Popularity score based on usage metrics
* **budget**: Estimated budget in USD
* **tagline**: Promotional tagline (if available)
* **keywords**: Important keywords or themes (stringified list)
* **production**\_**companies**: List of production companies (as a string)
* **cast**: Key cast members (as a string)
* **director**: Director’s name
