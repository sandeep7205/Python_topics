# 🐍 50 Python Terminal Projects (with Descriptions & Concepts)

## 🔰 Level 1 – Getting Started  
Basic logic, `if/else`, loops, `input()`, `print()`, and `random`.

1. **🥠 Fortune Cookie**  
   Generate a random fortune from a list.  
   _Concepts:_ `random.choice()`, lists, strings.  
   _Bonus:_ Save fortunes to a file.

2. **🎲 Dice Rolling Simulator**  
   Simulate rolling dice (d6, d20, etc.).  
   _Concepts:_ `random.randint()`, loops.  
   _Bonus:_ Support rolling multiple dice.

3. **🫱 Rock Paper Scissors**  
   Play against the computer.  
   _Concepts:_ Conditionals, loops, `random`.  
   _Bonus:_ Add score tracking.

4. **🫱 Rock Paper Scissors Lizard Spock**  
   The extended version.  
   _Concepts:_ Dictionaries for rules.  
   _Bonus:_ Multiplayer mode.

5. **🤑 Who Wants to Be a Millionaire**  
   Multiple-choice trivia game with increasing difficulty.  
   _Concepts:_ `if`, `elif`, scoring system.  
   _Bonus:_ Add lifelines (50:50, ask-a-friend).

6. **❓ Quiz Game**  
   Ask a series of questions and grade.  
   _Concepts:_ Lists, loops, scoring.  
   _Bonus:_ Load questions from a file.

7. **⚔️ Text-Based Adventure**  
   Navigate through story choices.  
   _Concepts:_ Functions, dictionaries.  
   _Bonus:_ Save/load player state.

8. **🤖 Chatbot**  
   Basic rule-based response bot.  
   _Concepts:_ `input()`, conditionals.  
   _Bonus:_ Add NLP with `re` or `nltk`.

9. **🙈 Truth or Dare**  
   Random truth/dare selector.  
   _Concepts:_ Lists, random.  
   _Bonus:_ Multi-user mode.

10. **🗓 Leap Year Checker**  
   Determine if a year is leap.  
   _Concepts:_ Modulo, conditionals.  
   _Bonus:_ Support year ranges.

11. **♣️ Baby Blackjack**  
   Simplified Blackjack.  
   _Concepts:_ Loops, score handling.  
   _Bonus:_ Dealer logic.

12. **♣️ Blackjack**  
   Full-featured terminal Blackjack.  
   _Concepts:_ OOP (cards, deck), logic.  
   _Bonus:_ Add betting and chip tracking.

13. **📏 Metric Conversion Tool**  
   Convert units like meters to feet.  
   _Concepts:_ Functions, input/output.  
   _Bonus:_ Add a CLI menu.

14. **📐 Area Calculator**  
   Calculate area for different shapes.  
   _Concepts:_ Functions, formulas.  
   _Bonus:_ Add perimeter/volume.

15. **🔢 Guess My Number**  
   User guesses a random number.  
   _Concepts:_ Loops, random.

16. **🔡 Word Counter**  
   Count words in a paragraph.  
   _Concepts:_ `split()`, `len()`.  
   _Bonus:_ Frequency of each word.

17. **🆘 Morse Code Translator**  
   Text ↔ Morse conversion.  
   _Concepts:_ Dictionaries.  
   _Bonus:_ Add audio output.

18. **🏛 Roman Numeral Converter**  
   Convert to/from Roman numerals.  
   _Concepts:_ Mapping logic.  
   _Bonus:_ Handle invalid input gracefully.

19. **🚇 NYC MetroCard Calculator**  
   Calculate balance after swipes.  
   _Concepts:_ Arithmetic, loops.  
   _Bonus:_ Add discounts and history log.

20. **🔐 Caesar Cipher**  
   Encrypt/decrypt with Caesar cipher.  
   _Concepts:_ Loops, ASCII, string indexing.
